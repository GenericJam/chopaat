# Asset scripts

Every binary asset in `priv/assets/` is generated by a script in this
directory (AGENTS.md: no asset without its generating script). Rebuild
everything with:

```
assets/scripts/build.sh      # blender x5, contact sheets, then the gate
node assets/scripts/gate.mjs # gate only (CI entry point)
```

## Conventions

- Right-handed Y-up, meters (Blender models Z-up; the glTF exporter
  converts with `export_yup=True`).
- Origin at logical center-bottom: geometry rests on y=0, centered in
  x/z (glTF frame).
- `.glb` only, embedded buffers, one file per asset.
- Every asset has a budget entry in `budgets.json`; the gate fails on
  a missing entry.

## Board addressing (the part the rules engine consumes)

Per RULESET.md. Every cell exports a named glTF node (an empty at the
cell's top surface):

- `cell_t{track}_l{lane}_r{row}` — track 0..arms-1 numbered
  counter-clockwise (absolute board frame; the per-player relative
  numbering in RULESET.md is the rules engine's mapping), lane 0/1/2,
  row 1 (nearest center) .. 8 (outer end).
- Lanes are labeled as seen **from the center looking outward**;
  lane 0 sits on the counter-clockwise side. This is forced by the
  movement path (RULESET.md step 3): track N's lane 0 top must cross
  into track N+1's lane 2 top.
- `base_t{track}` + `base_t{track}_seat_{0..3}` — off-board base pad
  beside each arm's outer end on the lane-2 side.
- `center_home` — the shared center.

Marked cells (distinct materials, same named nodes):

- Safe: lane 0 row 5 and lane 2 row 5 of every arm, and lane 1 row 6
  (final-stretch threshold) — `board_safe` material (blue).
- Gate: lane 2 row 5 (it *is* that safe cell but blocks passage) —
  `board_gate` material (ochre) plus a raised rim frame.

The gate (`gate.mjs`) asserts the complete node set for both boards.

## Cowrie orientation contract

Shells are authored resting **dome-up (aperture down)**, length along
+X, origin at the center of the resting plane. Aperture-up is a 180°
roll about X. The aperture faces carry the dark `cowrie_aperture`
material between two lip bulges so aperture-up vs aperture-down is
unmistakable from a 45° camera — this is what the tumble library
(chopaat-5gx) reads back after settle. RULESET.md throws 7 shells.

## Contact sheets (assets/contact_sheets/)

Headless EEVEE (Filmic view transform — AgX desaturates too much to
judge albedo, Standard clips the ivory shells):

- `shells_light.png` / `shells_dark.png` — all 10 variants × 3 poses
  (dome-up, aperture-up, side), labeled grid, 45° orthographic camera.
- `board_light.png` / `board_dark.png` — 4-player board from an
  elevated 45° game camera with pawns in all display poses (upright,
  tipped = final-stretch status, upside-down = reserved mad-pawn, in a
  base seat) and shells in the center.

These are the batched art-direction deliverable — one review round,
not per-asset pings.
